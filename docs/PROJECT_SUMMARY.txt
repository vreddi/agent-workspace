PROJECT VISION
A composable TypeScript toolkit for creating 2D interactive worlds that are:
- Logically grid-based underneath (for pathfinding, collision, AI, actions)
- Visually freeform on top (organic, cozy, artistic 2D rendering)
- Renderer-agnostic (PixiJS, Canvas, Three.js, or anything)
- React-friendly but React-independent in core
- AI-ready with structured actions as the control boundary

NOT a full game engine — a foundation for map editors, agent simulations,
cozy 2D worlds, interactive sandboxes.

KEY PRINCIPLES
1. Plain Objects > Classes (serializable, immutable-friendly state)
2. Actions as Control Boundary (AI proposes, simulation validates)
3. No Rendering in Core (headless-first, adapter-based rendering)
4. No React in Core (optional, thin integration layer)
5. No AI SDKs in Core (provider-agnostic, you choose AI)
6. Modular Packages (clear dependencies, one concern per package)
7. Grid-Based Logic, Freeform Visuals (discrete logic, organic art)
8. Events Over Callbacks (decoupled, replayable, testable)

PACKAGE ORGANIZATION (Milestone 1)
core               → Shared types, EntityId, events
grid               → Grid logic, coordinates, neighbors
world              → World state model, entities, terrain
agents             → Agent model and creation
actions            → Structured action types and validation
pathfinding        → A* pathfinding for square grids
movement           → Movement rules, collision checks
simulation         → Simulation engine, tick loop, dispatch
bundle             → Re-export common APIs
